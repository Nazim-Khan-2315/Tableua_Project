🚀 Getting Started

Follow these steps to explore the project files.

1. Clone the repository
git clone https://github.com/Nazim-Khan-2315/Tableua_Project.git

2. Navigate to the project directory
cd Tableua_Project

3. Open the project files

Check the repository for Tableau workbook files, datasets, and any supporting documentation.

Common Tableau file formats include:

.twb — Tableau workbook definition.
.twbx — packaged Tableau workbook, which can include supporting data and resources.
.csv and .xlsx — data files that may be used as workbook sources.
4. Open the workbook

Install Tableau Public or use a compatible Tableau Desktop installation.

Open the relevant workbook and follow its data connection requirements. If a workbook references an external dataset, make sure that the data source is available and correctly connected.
